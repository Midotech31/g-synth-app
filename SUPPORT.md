# Support

## Questions and use help

Open an issue at <https://github.com/Midotech31/g-synth-app/issues>. Include
the G-Synth version, operating system, installation route and a minimal input
that reproduces the problem. Do not post unpublished or sensitive sequence
data unless it is safe to make public.

## Scientific correctness reports

For an unexpected design or wet-lab outcome, include the input sequence,
enzyme pair, design options, exported provenance record and observed result.
Scientific discrepancies are treated as regression-test candidates.

## Security

Do not open a public issue for a vulnerability. Follow `SECURITY.md` and use
GitHub private vulnerability reporting.

## Support expectations

The maintainer will acknowledge reproducible scientific or security reports
within seven days when feasible. This research software is supplied without a
service-level guarantee or warranty; see the MIT licence.
