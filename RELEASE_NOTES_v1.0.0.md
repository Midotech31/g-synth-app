# G-Synth v1.0.0

G-Synth v1.0.0 is the first citable public release of the complete
design-to-sequencing workflow.

Highlights:

- verified PCR-free oligonucleotide assembly and restriction-enzyme cloning;
- translation-preserving codon optimisation and scientific preflight gates;
- vector, ligation, primer and sequencing-verification workflows;
- public reference-aligned ABI/AB1 chromatogram viewer with consensus, strand
  orientation, Phred-quality evidence and four-channel traces;
- machine-readable citation and Zenodo metadata;
- final generative-AI disclosure and reproducibility documentation;
- clean-release validation: 1,056 engine, 232 API and 57 frontend tests.

The archived insulin-glargine traces provide partial quality-admitted coverage;
they validate the post-sequencing workflow retrospectively but do not by
themselves prove complete-clone verification, expression or bioactivity.
