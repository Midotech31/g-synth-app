# Release notes — 11 September 2026

- Saved sequences are immutable; edits create a new project.
- Annotation writes validate coordinates and reject stale revisions.
- Delayed saves and scans cannot replace another project’s view.
- Evidence notes support 4,000 characters.
- GenBank import and export preserve coding frames on either strand and across the circular origin.
- Unsupported discontinuous features are rejected explicitly.
- Annotation review requires explicit selection and supports source notes.
- The sequence viewer supports feature search and circular coordinates.
- The annotation editor scrolls within desktop and mobile viewports.

References: [INSDC feature table](https://www.insdc.org/submitting-standards/feature-table/) and [inference vocabulary](https://www.insdc.org/submitting-standards/inference-qualifiers/).
